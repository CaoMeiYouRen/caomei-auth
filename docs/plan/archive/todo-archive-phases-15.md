### M1 窄屏首屏可用性

- **目标**: 登录方式、验证码行与 SSO 首屏在 390 / 360 下完整可用。
- **优先级**: P2（用户可见的移动端缺陷）。
- **范围**: `pages/login.vue` 的登录方式 Tab、`styles/_form.scss` / `components/base/input-v2.vue` 的 `.code-row`、`pages/sso-login.vue` 移动端顶部安全区。
- **验收标准**: 390 下 5 语言登录 Tab 均完整可见且无横向滚动；360 下验证码行不溢出、ja-JP 页面溢出归零；SSO 标题与语言切换器无重叠；桌面布局不变。
- **不做什么**: 不改登录方式顺序与文案、不隐藏手机号 Tab、不改验证码发送逻辑。
- **依赖**: 阶段 14 的 360 窄容器用例。
- **交付物**: 页面 / 样式改动、定向断言、受影响视觉基线。
- **风险与缓解**: Tab 换行改变高度 → 逐张归因重采 login 基线；code-row 被 2FA / 换邮箱复用 → 同批回归。

#### M1.1 登录页窄屏 Tab

- **目标**: 5 语言登录方式 Tab 在 390 / 360 下完整展示。
- **验收标准**: 390 / 360 / 768 下 Tab 组无横向溢出，三个 Tab 均可见；桌面（>768）布局不变，zh-CN 窄屏仅列宽分配与字号变化。
- **交付物**: `pages/login.vue` 样式、5 语言 × 390 / 360 / 768 几何断言；3 列改为 ≤768 生效，登录 390 / 768 四张基线重采。
- **依赖**: 无。

#### M1.2 验证码行窄屏换行

- **目标**: 找回密码 / 快速登录 / 2FA / 换手机号的验证码行在 360 下不溢出。
- **验收标准**: 输入 `flex: 1 1 0; min-width: 0`、按钮不压缩；360 下按钮不越出卡片、ja-JP 无页面溢出。
- **交付物**: `.code-row` 样式（输入 `flex: 1 1 0; min-width: 0`、按钮 `flex: none`、行内换行兜底）、5 语言 × 390 / 360 / 768 计算样式与几何断言（含 `two-factor-dialog` 自建行 360 单行断言）；找回密码 / 快速登录及 ja / ko 窄屏 8 张基线重采。
- **依赖**: 无。

#### M1.3 SSO 顶部安全区

- **目标**: SSO 标题与右上角语言切换器在移动端不重叠。
- **验收标准**: 390 / 360 下标题与切换器相交面积为 0；桌面不变。
- **交付物**: `pages/sso-login.vue` 移动端安全区（≤768 `padding-top: 4rem`）、5 语言 × 390 / 360 / 768 相交面积断言；SSO 移动端 6 张基线重采（zh-CN 390 浅 / 暗 2 张，ja / ko 各 390 浅 + 768 暗 4 张）。
- **依赖**: 无。

### M2 悬浮控件与遮挡

- **目标**: 固定主题切换与反馈按钮不再遮挡认证页可交互控件。
- **优先级**: P2（交互可用性）。
- **范围**: `layouts/default.vue`、`components/theme-toggle.vue`、`components/feedback-button.vue`、认证页右侧安全廊道与 SSO 顶部安全区。
- **验收标准**: 登录 / 注册 / SSO 页在 390 / 360 下，社交按钮、协议复选框、隐私链接、注册按钮、域名登录入口与悬浮按钮相交面积为 0；桌面布局不变。
- **不做什么**: 不重构悬浮按钮体系、不改按钮功能与位置锚点。
- **依赖**: M1。
- **交付物**: 安全区样式、相交断言、受影响基线。
- **风险与缓解**: padding 改变滚动高度 → 用相交面积断言并固定时钟。

#### M2.1 认证页安全区

- **目标**: 为登录 / 注册 / SSO 页预留右侧安全廊道，并给 SSO 标题预留顶部安全区。
- **验收标准**: 390 / 360 下内容不被固定按钮遮挡；页面无新增横向溢出。
- **交付物**: 认证页右侧安全廊道（≤768 登录 / 注册 `.auth-card` 收 4rem、SSO 页收 5rem，覆盖主题切换 right 16 + 44 与反馈按钮 right 16 + 约 46，任意滚动位置不相交）；5 语言 × 390 / 360 / 768 首屏与页底取样断言见 M2.2；22 张受影响基线重采。
- **依赖**: 无。

#### M2.2 遮挡相交断言

- **目标**: 用自动化断言锁住悬浮控件与关键控件的重叠。
- **验收标准**: 5 语言登录 / 注册 / SSO 页在 390 / 360 / 768 下相交面积为 0；内容右缘恒早于固定按钮；断言失败信息可定位控件。
- **交付物**: `mobile-auth-layout.visual.spec.ts` 首屏取样断言（廊道 + 控件相交 + SSO 卡片包含）。
- **依赖**: M2.1。

### M3 个人中心与 Admin 基础

- **目标**: 个人中心操作行与 Admin 后台在移动端达到基础可用。
- **优先级**: P3（体验）。
- **范围**: `pages/profile.vue` 操作行、`layouts/admin.vue` 侧栏、Admin 搜索 / 筛选输入字号。
- **验收标准**: 390 / 360 下个人中心操作行不溢出；Admin 移动端侧栏默认收起、输入字号 ≥16px、表格保持横向滚动；桌面不变。
- **不做什么**: 不做 Admin 数据表卡片化、不改侧栏结构与导航信息。
- **依赖**: 无。
- **交付物**: 页面 / 布局改动、定向断言。

#### M3.1 个人中心操作行换行

- **目标**: en-US / ja-JP 操作行在 390 / 360 下不溢出。
- **验收标准**: 操作行允许换行，按钮顺序与文案不变；页面无横向溢出。
- **交付物**: 操作行 ≤768 允许换行（`.profile-footer-actions`）；5 语言 × 390 / 360 / 768 按钮在行内与卡片内断言；profile 768 两张基线重采（容器字体下 zh-CN 也换行）。
- **依赖**: 无。

#### M3.2 Admin 侧栏默认收起

- **目标**: 移动端进入 Admin 时侧栏默认收起，首屏可见内容。
- **验收标准**: ≤768 首次进入侧栏为收起态；桌面与用户手动展开状态不受影响。
- **交付物**: `layouts/admin.vue` 挂载时按 `matchMedia` 初始收起；390 / 360 / 768 收起、1440 不收起断言；admin.visual 12 张与热力图 2 张基线重采，`admin-matrix` 就绪判定改 attached；收起态 aria-label、首帧展开残留登记 backlog §3.4。
- **依赖**: 无。

#### M3.3 Admin 输入字号与表格核验

- **目标**: 移动端搜索 / 筛选输入 ≥16px，表格继续横向滚动。
- **验收标准**: ≤768 输入字号 ≥16px；桌面 14px 不变；表格容器横向滚动且无页面溢出。
- **交付物**: Admin 主区 ≤768 表单控件字号 16px（桌面 14px 不变）；4 视口断言输入字号与表格横向滚动、页面无溢出；admin-users 平板两张基线重采。
- **依赖**: 无。

### M4 语言与跨语言基线

- **目标**: OAuth 入口跟随用户语言，并为移动端会话卡片补跨语言保护。
- **优先级**: P2 / P3（语言与回归）。
- **范围**: `lib/auth.ts` 的 `loginPage` / `consentPage`、`pages/oauth/consent.vue` 语言上下文、`security-session-cards` 视觉用例。
- **验收标准**: 已选 ja-JP / ko-KR 的用户从授权入口进入时渲染对应语言；5 语言 390 会话卡片基线入库且无溢出。
- **不做什么**: 不改全局 `detectBrowserLanguage.redirectOn`、不改 OAuth 协议与 state 语义。
- **依赖**: M3（布局稳定后采集）。
- **交付物**: 入口重定向、视觉用例、基线。

#### M4.1 OAuth 入口语言

- **目标**: 无语言前缀的 `/login`、`/oauth/consent` 按 cookie 补前缀。
- **验收标准**: 5 语言下入口语言正确；未登录 authorize 与已登录 consent 的 query / state 保留；无重定向循环。
- **交付物**: `server/api/oauth-entry/{login,consent}` 按 `i18n_locale` cookie 补前缀并保留 query；`server/utils/oauth-entry.ts` 纯函数 + 4 条单测；5 语言入口 302 断言。
- **依赖**: 无。

#### M4.2 会话卡片跨语言基线

- **目标**: 390 下 en-US / ja-JP / ko-KR / zh-TW 会话卡片元素基线。
- **验收标准**: 至少 2 张跨语言元素基线入库且全量视觉通过；无横向溢出。
- **交付物**: `security-session-cards` 补 en-US / ja-JP / ko-KR / zh-TW 390 元素基线 4 张（zh-CN 既有 2 张重命名为带 locale），按语言断言 6 个字段名，掩码 token / IP / 时间。
- **依赖**: M3。

- **范围**: 移动端视觉用例与基线、规范 / 设计文档、归档载体。
- **验收标准**: 5 语言 390 / 360 关键页矩阵通过（新增 ≤20 张）；lint / lint:css / typecheck / test / coverage / visual / build / docs:build 全绿；阶段正文归档、索引与 roadmap 同步。

- **交付物**: 视觉 spec、基线、文档、归档分片。
