### M1 平板断点收尾

- **目标**: 769–1024 的登录 Tab 与悬浮遮挡与 ≤768 保持一致可用。
- **优先级**: P2（平板 / 横屏用户可见缺陷）。
- **范围**: `pages/login.vue`、`pages/register.vue`、`pages/sso-login.vue`、`tests/visual/baseline/mobile-auth-layout.visual.spec.ts`。
- **验收标准**: 769 / 800 / 1024 下登录 Tab 无组内横向滚动且三个 Tab 完整可见；内容右缘早于固定按钮（相交面积 0）；页面无横向溢出；>1024 桌面不变。
- **不做什么**: 不改登录方式顺序与文案、不改悬浮按钮锚点、不改认证流程。
- **依赖**: 阶段 15 的廊道与 Tab 断言。
- **交付物**: 断点扩展样式、769 / 800 / 1024 断言。
- **风险与缓解**: 廊道收窄使长语言换行增多 → 1024 基线逐张归因；1024 卡片更宽 → 先断言再采基线。

#### M1.1 登录 Tab 扩到 ≤1024

- **目标**: 3 列自适应覆盖 769–1024。
- **验收标准**: 769 / 800 / 1024 下 5 语言 Tab 均完整可见、组内不可横向滚动。
- **交付物**: `pages/login.vue` 媒体查询扩展、3 视口断言。
- **依赖**: 无。

#### M1.2 右侧安全廊道扩到 ≤1024

- **目标**: 登录 / 注册 / SSO 内容右缘在 769–1024 早于固定按钮。
- **验收标准**: 769 / 800 / 1024 下控件与主题切换 / 反馈按钮相交面积为 0，页面无横向溢出。
- **交付物**: 三页廊道媒体查询扩展、3 视口相交断言。
- **依赖**: 无。

#### M1.3 平板断点几何断言

- **目标**: 把 769 / 800 / 1024 纳入现有几何用例矩阵。
- **验收标准**: `mobile-auth-layout` 覆盖 769 / 800 / 1024；回滚断点扩展时必红。
- **交付物**: 视口矩阵与断言。
- **依赖**: M1.1、M1.2。

### M2 1024 横向视觉矩阵

- **目标**: 为 1024×768 关键页补像素保护。
- **优先级**: P2（回归保护）。
- **范围**: `tests/visual/baseline/` 新 spec 或扩展矩阵、4 张基线。
- **验收标准**: login / register / security / admin-users 各 1 张 1024×768 浅色基线入库，全量视觉通过。
- **不做什么**: 不采双主题、不扩到全站全页。
- **依赖**: M1（布局稳定）。
- **交付物**: 1024 用例与 4 张基线。
- **风险与缓解**: CI 时长 → 只 4 张浅色；admin 页需管理员会话 → 复用 `useAdminSession`。

#### M2.1 1024 × 768 四页基线

- **目标**: 4 页 1024 横向整页基线。
- **验收标准**: 4 张基线入库且全量视觉通过；页面无横向溢出。
- **交付物**: 1024 spec 与基线。
- **依赖**: M1。

### M3 SSO 暗色主题

- **目标**: `/sso-login` 在暗色模式下内容与页脚一致。
- **优先级**: P3（体验一致性）。
- **范围**: `pages/sso-login.vue`、`styles/_dark-mode.scss`、暗色基线。
- **验收标准**: 390 / 768 暗色下内容区使用暗色 token，无浅色卡片残留；暗色基线 2 张入库；桌面浅色不变。
- **不做什么**: 不做视觉改版、不改布局结构。
- **依赖**: 无。
- **交付物**: 暗色 token 接入、2 张暗色基线、断言。
- **风险与缓解**: token 映射错误 → 计算样式断言关键背景 / 文字色；与浅色基线隔离。

#### M3.1 SSO 暗色 token 接入

- **目标**: 用既有暗色 token 替换硬编码浅色。
- **验收标准**: 页面背景、方法卡、提供方卡、页脚在暗色下同属暗色系；无低对比文字。
- **交付物**: `sso-login.vue` 与 `_dark-mode.scss` 改动。
- **依赖**: 无。

#### M3.2 SSO 暗色基线与断言

- **目标**: 锁住 390 / 768 暗色渲染。
- **验收标准**: 2 张暗色基线入库；关键元素背景 / 文字计算样式断言通过。
- **交付物**: 视觉用例、基线、断言。
- **依赖**: M3.1。

### M4 Admin 导航可访问性与首帧

- **目标**: 收起态导航可被读屏识别，首帧不再跳变，参考态漂移有登记。
- **优先级**: P2（可访问性 / 体验）。
- **范围**: `layouts/admin.vue`、`tests/visual/helpers/admin-matrix.ts`、参考态登记、视觉基线。
- **验收标准**: 全部导航链接均有 `aria-label`（登记记录写 10 个，实际 `nav-item` 为 9 个，见收口记录偏差）；≤768 首帧即为收起态（无展开→收起跳变），桌面与手动展开不受影响；参考态漂移清单入库。
- **不做什么**: 不改导航信息与顺序、不做抽屉式导航。
- **依赖**: 阶段 15 M3.2。
- **交付物**: 布局改动、断言、参考态登记。
- **风险与缓解**: CSS-first 改动显示控制 → 重采 12 张基线并归因；首帧断言需在 hydration 前取样。

#### M4.1 导航 aria-label

- **目标**: 收起态全部导航链接有可访问名称。
- **验收标准**: 每个 `NuxtLink` 常驻 `aria-label`；读屏与 axe 规则无回归。
- **交付物**: 模板改动、可访问性断言。
- **依赖**: 无。

#### M4.2 CSS-first 首帧收起

- **目标**: ≤768 首帧即收起，无展开→收起跳变。
- **验收标准**: 首帧 HTML 的侧栏为收起样式；用户手动展开 / 收起正常；桌面不变。
- **交付物**: 布局样式与状态改动、首帧断言、12 张基线重采。
- **依赖**: 无。

#### M4.3 参考态漂移与就绪判定

- **目标**: 登记 admin 移动端参考态永久漂移，恢复内容区就绪守卫。
- **验收标准**: 漂移清单（12 张 + 原因 + 豁免）入库；`admin-matrix` 就绪文案收敛到主内容区。
- **交付物**: 测试规范 / 参考态文档、helper 调整。
- **依赖**: M4.2。
