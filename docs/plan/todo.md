### M1 契约与端点

- **目标**: `require_pkce` 从入参到落库、到视图全链路可用，新建默认 `true`。
- **优先级**: P2（安全配置能力缺失）。
- **范围**: `utils/shared/schemas.ts`、`server/api/admin/oauth/applications/index.post.ts`、`[id].put.ts`、`server/utils/oauth-client-view.ts`、`types/admin.ts`、相关单测。
- **验收标准**: 不传时新建为 `true`；显式传 `false` 时落库 `false`；PUT 只改显式传入值；视图返回 `requirePkce`；存量客户端不变。
- **不做什么**: 不改 PKCE 校验、不改客户端认证流程。
- **依赖**: 无。
- **交付物**: Schema、端点、视图、类型、单测。
- **风险与缓解**: 默认值变化影响新接入方 → 创建对话框给出说明与开关；文档标注默认值变化。

#### M1.1 Schema 增加 require_pkce

- **目标**: 创建 / 更新 Schema 接受 `require_pkce` 布尔值。
- **验收标准**: `oauthApplicationSchema` / `oauthApplicationUpdateSchema` 均接受该字段；未传时为 `undefined`。
- **交付物**: Schema 改动、类型导出、单测。
- **依赖**: 无。

#### M1.2 创建端点默认 true

- **目标**: 删除硬编码 `requirePKCE = false`，未传时按 `true` 落库。
- **验收标准**: 未传 → `true`；传 `false` → `false`；响应体含最终值。
- **交付物**: 端点改动、单测。
- **依赖**: M1.1。

#### M1.3 更新端点透传

- **目标**: `PUT` 只在显式传值时更新 `requirePKCE`。
- **验收标准**: 传 `true` / `false` 生效；不传时保持原值（含存量 `false`）。
- **交付物**: `applyOAuthClientInput` 与端点改动、单测。
- **依赖**: M1.1。

#### M1.4 视图字段与契约测试

- **目标**: 管理端视图返回 `requirePkce`，并有契约断言。
- **验收标准**: `toAdminOAuthClientView` 返回布尔值；`types/admin.ts` 类型同步；契约测试通过。
- **交付物**: 视图、类型、测试。
- **依赖**: M1.2。
