## 2. 最终路由白名单

```text
/login, /register, /forgot-password, /change-password, /quick-login,
/profile, /security, /oauth/consent, /sso-login,
/admin/users, /admin/oauth/applications, /admin/sso/providers, /admin/logs,
/oauth/clients, /
```

- 根路径 `/` 为**精确匹配**（`isCaomeiUiRoute` 对 `/` 单独处理），不把全部路由算作白名单。
- `error.vue` 无路由前缀（Nuxt 错误实例），不登记白名单；`components/theme-toggle.vue` 等共享壳组件不再按路由分叉（M11 起默认 / Admin 布局共用同一实现）。
- 白名单在 P5（M14）随迁移守卫一并删除。

## 5. 视觉

- **自基线（阻断门禁）**：`pnpm test:visual` **102 passed**（100 张截图 + 2 条主题切换 hover / active 对比度断言）。Admin 38 + 认证 62（含 about / privacy / terms 12 张新增自基线）。
- **参考态（审计层，不阻断）**：`pnpm test:visual:parity` 结果 **0 passed / 88 diff**（参考态 88 张；about / privacy / terms 的 12 张自基线页面在参考态层跳过，不计入总数）。差异归因：
    1. **P4-0 全局基座**：PrimeVue `darkModeSelector` 修复（暗色组件 token 真正生效）、`--admin-*` token 接管页面容器 / 表头 / 分页器。
    2. **逐批页面迁移**：DataTable / Button / Input / Select / Dialog / Tag 换库带来的结构、密度、圆角、配色与宽度档位变化（M2–M11 记录逐项登记）。
    3. **共享壳组件**：`BaseTooltip` 全站统一（`73f0f55`）、ThemeToggle 单一实现（M11）、Avatar 上传按钮修正。
    4. **夹具与页面新增**：`/sso-login` 底部 Provider 卡片受 Admin 夹具影响；about / privacy / terms 为迁移后新增页面（`reference: false`，不参与参考态）。
    5. **认证面桥接修正**（M3-2 起）：字段高度 / 字号 / 按钮尺寸按 caomei token 收敛。
- **参考态不原地刷新**：按[视觉参考态基座](./2026-11-08-visual-baseline-harness.md) §6，参考态是迁移前原貌的历史证据；M12 **不重新采集**参考态，也不把 parity 转为阻断门禁。P5 完成后参考态仅作历史保留。
- 已登记视觉盲区（backlog）：长对话框内部滚动区不在首屏截图范围；视觉层固定时钟导致对话框内 `CaomeiSelect` 鼠标交互失败（真实时钟正常）；图表 hover / 动画不进入截图。
