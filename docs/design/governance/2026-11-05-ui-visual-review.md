## 2. 发现与处置

| # | 问题 | 严重度 | 处置 |
| :-: | :--- | :--- | :--- |
| 1 | 暗色下 GitHub / Apple 社交按钮文字与图标几乎不可见（品牌色为深色，未使用 `darkColor`） | 高 | 改为同时输出明暗品牌色 CSS 变量，由 `.dark` 选择器切换 |
| 2 | 注册页「我已阅读并同意…」在暗色下不可读（`$secondary` 未做暗色覆盖） | 高 | 增加暗色颜色覆盖 |
| 3 | 主题选择刷新后丢失；系统为暗色时首屏图标 / `aria-pressed` 与页面不一致 | 中 | 新增 `useAppTheme`（`auto/light/dark` 唯一事实源），主题按钮挂载前统一按浅色渲染，挂载后同步 |
| 4 | 主题按钮在系统暗色下产生 hydration 图标 / 文案不一致 | 中 | 同上；`mounted` 门控后不再出现 mismatch |
| 5 | 后台暗色侧边栏中的语言胶囊仍是白底 | 低 | 侧边栏内 `:deep` 暗色覆盖 |
| 6 | 社交按钮颜色依赖 `isDark`，SSR 与客户端不一致 | 中 | 明暗色都交由 CSS 变量切换，SSR 不依赖系统主题 |

## 3. 验证证据

- Playwright（系统暗色）：`html.dark`、主题图标为月亮、`aria-pressed=true`、GitHub 按钮颜色 `rgb(255,255,255)`，控制台 hydration 警告 **0**。
- 主题持久化：`light → 点击 → dark`，刷新后仍为 `dark`（localStorage `vueuse-color-scheme=dark`）。
- 注册页暗色：协议文案颜色 `rgb(255,255,255)`。
- 后台侧边栏胶囊暗色：背景 `rgb(30,30,30)`、文字 `rgb(255,255,255)`。
- 主色 / 布局：登录与后台按钮仍为 `#e63946`，页面背景与字体未受 caomei-ui 基座影响。
