## 2. 实现要点

- **索引放量门禁**：只有 `readiness === 'seo-ready' && indexable` 的语言进入 hreflang、`og:locale:alternate` 与 sitemap；`draft` / `ui-ready` 语言不会泄漏进索引。
- **运行时 origin**：`@nuxtjs/i18n` 的 `baseUrl` 在构建期固化，部署域名与构建环境不一致时会写出 `localhost`；`app.vue` 统一把 canonical / hreflang / `og:url` 的 origin 归一到「配置的站点地址优先，其次当前请求源」（SSR 用 `useRequestURL`，客户端挂载后取 `location.origin`），配置值末尾斜杠会被规范化。
- **sitemap 口径**：只列未登录可访问的静态页（登录 / 注册 / 忘记密码 / 快速登录 / SSO / 关于 / 隐私 / 条款）；首页需要登录（302），不收录，Admin 与登录后页面同样不进入；每个 URL 附带两种语言与 `x-default` 的 `xhtml:link`。
- **robots 与页面 `noindex` 双保险**：robots 负责常规抓取，页面级 `noindex` 防止外链或历史索引残留。
- **x-default**：沿用 `@nuxtjs/i18n` 输出（指向默认语言），与 canonical 一致。

## 4. 已知边界

- sitemap 不包含首页与动态内容页（首页需登录、OAuth 授权页 / 回调页不应索引）。
- Admin 页面的英文渲染由批次内浏览器抽检覆盖，不进入像素基线（数据随用例顺序变化）。
- `x-default` 指向默认语言，未单独配置多语言选择页。
- Registry 放量后，英文页面进入索引的前提是部署域名正确传 `Host` 或显式配置 `NUXT_PUBLIC_AUTH_BASE_URL`；h3 默认不读取 `X-Forwarded-Host`。
- 未接入外部站长平台（Search Console / Bing）验证，属运营动作。
