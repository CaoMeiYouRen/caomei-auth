## 2. 1.1.0 / 1.2.0 变更摘要

来源：GitHub Releases `v1.1.0` / `v1.2.0` + tarball `dist/`。

### 1.1.0（2026-11-06）

- **新增 `CaomeiForm` / `CaomeiFormItem`**：布局与 submit 编排 + `id` / `name` / `aria-labelledby` / `aria-describedby` / `invalid` 插槽作用域；**无 rules 引擎**，校验仍归消费方。
- **新增 `data-density="touch"` 密度轴**：控件 36 / 44 / 52，字号 14 / 16 / 18；未设置时逐值不变。
- **a11y**：P0 清除 / 关闭按钮命中区扩到 ≥ 24×24（`--caomei-hit-target-min`）。
- 其余为发布链与仓库治理，不影响运行时。

### 1.2.0（2026-11-08）

- **`DatePicker` 支持 `selectionMode="range"`**：`v-model` 为 `[Date, Date]` 闭区间，未选为 `null`；依次点击起止；`closeOnSelect` 默认 `true`；`multiple` 未实现。
- **Toast 逐语气 token**：`--caomei-toast-{primary|success|warning|danger}-{bg|border|text|shadow}` 共 16 个；`neutral` 沿用全局；缺省零视觉变化（相对 caomei-ui 默认）。
- **DataTable 迁移适配**：新增 `--caomei-data-table-cell-padding-block` / `-cell-padding-inline` / `-selection-column-width` / `-selection-cell-padding-inline`；**不新增 `size` prop**；Paginator 仅补自渲染报表示例。
- 图标体系仅调研，未改依赖。

## 6. 修订后的口径

1. **版本**：迁移目标固定 `1.2.0`，Dependabot 阻断 `>1.2.0`；后续升级走人工批次。
2. **DatePicker**：`admin/logs` 使用 `selectionMode="range"`（P4），不再双日期选择器、不保留 PrimeVue 例外。
3. **Toast**：token 映射为主，`info` 走 `neutral`，不建薄封装；圆角 / 间距 / 标题 / 描述色差异登记。
4. **表单**：`CaomeiFormItem` 承接布局与 aria；`useForm` + Zod 校验不变。
5. **DataTable**：密度与选择列宽度用 token 覆盖；Paginator 报表继续自渲染；表头全选作用域待业务确认。
6. **新增能力暂不采用**：`data-density="touch"` 属交互 / 设计变更，不在 P2–P3 范围；如需移动端密度单独立项。

## 7. 残余风险

- `DatePicker` range 的清空交互与 PrimeVue 不同（无 `showClear`），P4 需在视觉 / 交互基线上逐项确认。
- Toast 的 16 个 token 只覆盖根元素颜色；旧观感的圆角 8px、内边距、标题字号无法通过 token 还原。
- `CaomeiFormItem` 无 rules 引擎，若被误用为校验层会导致双轨；登记规范已在评估 §9 风险 4.1。
- 1.2.0 发布不足 `minimumReleaseAge`，`pnpm-workspace.yaml` 的 exclude 属预期；下一次 `pnpm install` 不应再触发提示。
- 上游 [#28](https://github.com/CaoMeiYouRen/caomei-ui/issues/28) 可关闭或更新：DatePicker range、Toast token、DataTable 密度 / 选择列宽度已交付，Paginator 报表仍为自渲染方案。
