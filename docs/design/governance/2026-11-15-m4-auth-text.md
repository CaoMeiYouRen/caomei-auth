## 2. M4-1 实现

| 面 | 内容 |
| :--- | :--- |
| 翻译入口 | 新增 `composables/utils/use-i18n-text.ts`：从 `nuxtApp.$i18n` 取全局 composer，组合式函数与单测都可调用（`useI18n()` 在 setup 外会抛错）；缺键 / 抛错时回退键名，不中断流程 |
| 键结构 | `auth.common.*`（通用提示）、`auth.login.*`、`auth.register.*`、`auth.forgot.*`、`auth.quickLogin.*`、`auth.changePassword.*`、`auth.code.*`、`auth.phone.*`、`auth.captcha.*`、`auth.password.*`、`auth.left.*`；中英各 77 键（含密码强度 / 要求 / 错误 17 键） |
