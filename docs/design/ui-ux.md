# UI/UX 设计规范

本文档定义了草梅 Auth 的视觉识别系统 (VI) 和用户体验准则。

## 1. 视觉风格

项目采用现代、明快且具有安全感的视觉风格，基调以红色为主，象征活力与警示。

### 主题色规范

| 变量名            | 色值      | 用法                   |
| :---------------- | :-------- | :--------------------- |
| **Primary**       | `#e63946` | 主按钮、链接、激活状态 |
| **Primary Light** | `#ff6b6b` | 悬停状态、浅色背景元素 |
| **Primary Dark**  | `#a52834` | 点击状态、深色背景元素 |
| **Background**    | `#f8fafc` | 默认页面背景           |
| **Surface**       | `#ffffff` | 卡片、输入框背景       |

### 调色板 (PrimeVue Palette)

-   50: #ffe5e9
-   500: #e63946 (Base)
-   950: #3a0c12

## 2. 图标与字体

-   **图标库**: 统一使用 `@mdi/font` (Material Design Icons)。
-   **字体**: 优先使用系统默认无衬线字体堆栈。

## 3. 布局与响应式

-   **断点**: 遵循 Tailwind/PrimeFlex 标准。
-   **移动端优先**: 保证所有功能在移动端浏览器下均有完整的操作体验。
-   **管理后台**: 采用侧边栏/顶栏混合布局，支持折叠。桌面宽度下主内容区允许收缩（`min-width: 0`），宽表格与热力图在各自容器内滚动，不把页面撑出横向滚动条；`/admin/logs` 在 1440 下筛选行允许换行，769–1240 窄桌面不裁切控件。
-   **移动端会话表**: ≤768 渲染卡片式会话项（令牌 / 浏览器 / 系统 / IP / 时间 / 操作竖排），769 起恢复表格；桌面列语义不变。
-   **认证窄屏基线**: ja / ko 的 register、forgot-password、sso-login 覆盖 390 浅色与 768 暗色整页基线，360 窄容器用例保证无横向溢出。已知缺口：`/sso-login` 页面暗色主题尚未实现，暗色基线呈现浅色内容 + 暗色页脚，修复候选见 [backlog §3.4](../plan/backlog.md#34-ui-与主题)。

## 4. 组件规范

-   **表单**:
    -   必须包含校验状态反馈（错误提示、成功状态）。
    -   关键操作需有 Loading 状态拦截重复点击。
-   **反馈**:
    -   成功操作使用绿色 Toast。
    -   错误异常使用红色 Banner 或对话框。
